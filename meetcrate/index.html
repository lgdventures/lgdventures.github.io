Features

What is MeetCrate?

MeetCrate is a browser extension for Read AI users (on Google Chrome and Microsoft Edge) that exports every meeting at once (transcripts, summaries and action items as Markdown, TXT, SRT or JSON in one ZIP) through Read AI’s official, read-only sign-in. Files are created on your computer; nothing is sent to an LGD Ventures server.

Read AI downloads meetings one at a time. MeetCrate exports all of them at once, ready for Obsidian, Notion, Drive or a plain folder.

Everything in one ZIP

One file per meeting with the summary, action items as a checklist, chapters, key questions, topics and the full transcript with speakers and timestamps. Plus an index.csv with one row per meeting.

Markdown, TXT, SRT & JSON

Markdown with YAML front matter for Obsidian and Notion, plain text, subtitles with speaker names, and the raw API JSON so nothing is lost.

Only new since last export

Next time, export just the meetings you haven’t exported yet. Ideal for a weekly backup.

Resumable, rate-limit friendly

Close the tab or lose Wi-Fi and the export continues where it stopped. Meetings still processing are skipped and retried in one click.

Private by design

You sign in on Read AI’s own page. Files go straight from Read AI to your computer: no MeetCrate account, no servers, no analytics.
