How to Export Read AI Transcripts in Bulk (2026)

How do you export Read AI transcripts in bulk?

Quick answer: Read AI’s Download button saves one meeting report at a time. For a bulk ZIP (Markdown, TXT, SRT or JSON), install MeetCrate, connect with Read AI’s official sign-in, and export. Free for 25 exported meetings in total; Pro is US$29 one-time (as of Oct 2026). Everything runs locally in Chrome or Edge.

Last checked 2026-11-09. Official Read AI download steps cite Read Help Center. MeetCrate features were checked against the live landing and extension 0.3.1.

Method 1 — Read AI’s own Download (one meeting at a time)

Per Read AI Help, anyone who can view a meeting report can download parts of it (unless a workspace admin turned Downloads off):

  1. Open the meeting report in Read AI.
  2. Click Download near the top right.
  3. Choose what you need (for example Transcript as .txt, or Recap).

Limits to expect: there is no multi-select. You repeat the steps for every meeting. File names and formats are whatever Read AI offers for that item. Useful for one or two meetings; slow for an archive.

Method 2 — Read AI API (for developers)

Read AI also offers a REST API (open beta) so you can list meetings and pull transcripts programmatically with OAuth. You only get meetings your account can already see, and you handle pagination, tokens and file formatting yourself. See Read AI API overview.

Method 3 — MeetCrate bulk ZIP

MeetCrate is a Chrome and Edge extension that connects through Read AI’s official sign-in (read-only) and exports meetings to files on your computer:

  1. Install MeetCrate from the Chrome Web Store or Edge Add-ons.
  2. Open MeetCrate and connect Read AI. You sign in on Read AI’s own page; MeetCrate never sees your password.
  3. Pick the meetings (or “only new since last export”) and choose Markdown, TXT, SRT or JSON.
  4. Download one ZIP: one file per meeting plus an index.csv. Next time you can export only meetings you have not exported yet.

Free: 25 exported meetings in total. Pro: US$29 one-time (as of Oct 2026), no subscription, up to 3 browsers. Meetings go from Read AI to your computer; LGD Ventures runs no servers that receive your meetings. Privacy policy.

FAQ

Does MeetCrate work on Read AI Free?

Yes. MeetCrate only reads meetings your Read AI account can already see. Any Read AI plan that has the official API, including Free, works.

Is it private?

You sign in on Read AI’s page; MeetCrate gets a read-only token that stays in your browser. Exported files stay on your computer. See the privacy policy.

Can I also export Fathom?

Yes. The same extension supports Fathom with your own API key. See the Fathom bulk export guide.

What is inside each file?

Title, date, duration, participants, summary, action items and the full transcript with speakers and timestamps. Read AI meetings also include chapters, key questions and topics when Read AI has them.
