ChatGPT & Claude to Obsidian: Notes and Tasks in Minutes

GuideLast checked 2026-10-18 · Sources linked inline

Quick answer: Copy-paste works until code fences break. ChatCairn exports Markdown with YAML front-matter and can turn highlights into Obsidian Tasks lines with due dates.

Last checked 2026-10-18. Obsidian Tasks emoji syntax cites the official Tasks plugin docs. The ChatCairn formats below were checked against the 0.3.0 exporter.

Who this is for

Obsidian and PKM users who plan work with ChatGPT or Claude (and want the same flow for Gemini/Grok).

Manual way

  1. Select text in the chat → copy.
  2. Paste into a Markdown note.
  3. Fix broken code fences, tables and list indentation by hand.

Fine for short answers; painful for long threads with code.

ChatCairn → Markdown

Save the conversation, then click Export Markdown (popup or library). Each file starts with YAML front-matter that Obsidian reads as Properties, then one heading per message. Example shape (synthetic):

---
title: "Example: parsing nested JSON"
source: ChatGPT
url: https://chatgpt.com/c/example
saved: 2026-10-18T14:05:12.000Z
tags: [ai-chat, chatgpt]
---

# Example: parsing nested JSON

## You
How do I parse nested JSON in Python?

## ChatGPT
Use json.loads, then walk the dict…

Highlight → Obsidian Tasks

Select text in an answer (on the AI site or in the ChatCairn library) → Task, with an optional project and due date. Then open Notes & Tasks → Export Markdown; tasks from a chat are also added to that chat’s own Markdown export. The exporter builds lines like:

- [ ] Draft the migration checklist #project-name 📅 2026-10-20
  > Start with a list of every table that changes…
  Source: [Example: database migration plan](https://chatgpt.com/c/example)
- [x] Send the brief #ops 📅 2026-10-18 ✅ 2026-10-18

Due dates use the Obsidian Tasks due-date signifier 📅 YYYY-MM-DD per the Tasks plugin Dates docs. Projects are emitted as tags (#…). Done tasks may include ✅ with a done date. Each line keeps the highlighted quote and a link to the source chat underneath. Install the community Tasks plugin in Obsidian to query these lines.

Suggested Tasks query:

```tasks
not done
due before tomorrow
```

Vault layout (suggestion)

  • AI chats/ — imported Markdown exports
  • Tasks/ — ChatCairn tasks export or a single running tasks note

Notion

FAQ

Do I need Pro?

Free includes Markdown/PDF export and notes/tasks up to the free limits (50 chats, 10 notes/tasks). Pro adds unlimited chats and notes, plus a bulk ZIP export of your whole library.

Does export upload my vault?

No. Exports are files you download. Chat content stays local unless you put the file somewhere yourself.
